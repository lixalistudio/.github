# .github

Organization profile and default community health files for [Lixali Studio](https://github.com/lixalistudio).

GitHub uses the files in this repository for every repository of the organization, public or private, that does not have its own:

| File                                                                   | Used for                                                                 |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| [`profile/README.md`](profile/README.md)                               | The organization's profile page                                          |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)                             | Code of conduct                                                          |
| [`CONTRIBUTING.md`](CONTRIBUTING.md)                                   | Contribution guide, linked when someone opens an issue or a pull request |
| [`SECURITY.md`](SECURITY.md)                                           | Security policy, shown under each repository's Security tab              |
| [`SUPPORT.md`](SUPPORT.md)                                             | Where to ask for help                                                    |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/)                   | Bug report and feature request forms                                     |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Pull request description                                                 |

A file in a project's own repository always wins over the one here. A repository with its own `.github/ISSUE_TEMPLATE/` folder uses none of the issue templates from here.

This repository is public, as GitHub requires. Put nothing here that should not be: no client names, internal links or secrets.

Licenses are not inherited: each project needs its own `LICENSE` file.

Open source projects live in [lixalistudio-oss](https://github.com/lixalistudio-oss), which has its own [`.github`](https://github.com/lixalistudio-oss/.github).
